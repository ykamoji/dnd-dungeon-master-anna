# D&D Dungeon Master Anna UI

This is the copied React client adapted to Anna's bundled Executa and user-scoped storage. Its screens and visual styling remain the source client’s React implementation. It is built as a static Next.js export because Anna serves `static-spa` bundles rather than a server-rendered React runtime.

## Develop and build

From the repository root:

```sh
npm install --prefix ui
npm run dev --prefix ui
# Production export: npm run build --prefix ui
```

The local Next.js preview uses browser localStorage and a deterministic sample campaign when Anna’s SDK is unavailable. `npm run build --prefix ui` exports to `ui/out/` and copies the static site into the Anna app’s `bundle/` directory. The copy script preserves the `bundle/anna-tool-ids.js` mapping generated by Anna’s CLI and writes exact SHA-256 hashes for Next hydration scripts to `manifest.ui.csp_overrides`, because Anna blocks inline scripts by default.

## Architecture

- `src/components/` and `src/context/` preserve the source client’s React screens and guided campaign flow.
- `src/lib/api.ts` adapts the UI to Anna user-scoped storage and the bundled `dnd-game-master` Executa.
- `src/components/game/console/ConsoleProvider.tsx` handles campaign creation, turn drafts, approval/rejection, and history refresh.
- `next.config.mjs` configures static export with relative Next.js chunk paths. Runtime routes and server rewrites are not used.

The UI uses locally bundled artwork and fonts. It does not fetch published adventure maps or campaign assets.
